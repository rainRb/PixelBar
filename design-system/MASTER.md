# PixelBar Design System

## Pattern
Minimal single-column tool UI · dark audio aesthetic · block-based sections

## Colors
| Role | Hex |
|------|-----|
| Primary | `#1E1B4B` |
| Secondary | `#4338CA` |
| Accent / CTA | `#22C55E` |
| Background | `#0F0F23` |
| Foreground | `#F8FAFC` |
| Muted surface | `#27273B` |
| Border | `#312E81` |
| Destructive | `#EF4444` |

## Typography (WinUI)
- Page title: 28px SemiBold
- Section label: 14px SemiBold
- Body: 14px Regular
- Caption: 12px Secondary

## Spacing
4 / 8 / 16 / 24 / 32 rhythm · page padding 32,28,32,40 · section gap 24

## Components
- Section cards: 12px radius, 1px border, optional accent stripe
- Primary CTA: accent fill, 44px height
- Connection badge: semantic green / red dot
